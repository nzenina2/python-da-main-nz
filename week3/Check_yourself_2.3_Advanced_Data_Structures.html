2 · The four common combinations

        

          
list of lists
[[1, 2, 3],
 [4, 5, 6]]
a table / matrix

          
list of dicts
[{"name": "Anna", "grade": 9},
 {"name": "Janis", "grade": 7}]
records = rows

          
dict of lists
{"Riga": [12, 14, 9],
 "Cesis": [10, 11, 8]}
key → a series

          
dict of dicts
{"Riga": {"pop": 605000, "area": 307},
 "Cesis": {"pop": 14000, "area": 19}}
record per key; graphs

        

        
Rule: a list is indexed by position [0], a dictionary by key ["Riga"]. Mixing them up gives TypeError / KeyError.

      

    


    
Graphs — four types, one Python trick

    
A graph = vertices + edges. The type only changes how we store the edges.

    

      
Undirected
friends = {"Anna": {"Janis", "Marta"},
           "Janis": {"Anna", "Marta"},
           "Marta": {"Anna", "Janis", "Olegs"},
           "Olegs": {"Marta"}}
edge stored in both directions

      
Directed
follows = {"Anna": {"Janis", "Marta"},
           "Janis": {"Marta"},
           "Marta": {"Anna"},
           "Olegs": {"Anna", "Marta"}}
edge stored in one direction

      
Weighted
distance = {"Riga": {"Jelgava": 42, "Jurmala": 25, "Ogre": 36},
            "Jelgava": {"Riga": 42},
            "Jurmala": {"Riga": 25},
            "Ogre": {"Riga": 36}}
dict of dicts: neighbour → number

      
Disconnected
groups = {"Anna": {"Janis", "Marta"}, "Janis": {"Anna", "Marta"},
          "Marta": {"Anna", "Janis"},
          "Olegs": {"Ilze"}, "Ilze": {"Olegs"}}
two parts, no edge between them

Trees and forests

    

      

        
Tree = a hierarchy

        

        
One root; every other vertex has exactly one parent; vertices without children are leaves. No cycles → exactly one path between any two vertices. n vertices → n − 1 edges.

        
In Python: a dictionary whose values are dictionaries, down to the leaves. One for per level.

      

      

        
Forest = a list of trees

        

        
Several trees, not connected to each other. Random forest (week 8): many slightly different decision trees vote; the majority wins. One tree can be wrong — a hundred trees rarely agree on the same mistake.
